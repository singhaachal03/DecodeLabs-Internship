# Rule-Based AI Chatbot

## Description

This project is a simple rule-based AI chatbot developed as part of my Artificial Intelligence internship at DecodeLabs.

The chatbot interacts with users through predefined rules and provides responses based on the user's input. It uses conditional logic and a continuous conversation loop to simulate basic human-computer interaction.

## Features

- Responds to greetings such as `hi`, `hello`, and `hey`
- Answers predefined questions
- Provides information about the chatbot
- Provides a help command
- Handles unknown inputs with a fallback response
- Supports exit commands such as `bye`, `exit`, and `quit`
- Maintains a continuous conversation until the user exits

## Technologies Used

- Python
- Conditional statements (`if`, `elif`, `else`)
- Loops
- Functions
- User input handling
